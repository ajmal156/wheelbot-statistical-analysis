## Dataset and Attribution

This project uses the **Mini Wheelbot Dataset** developed for research on learning-based control and robot dynamics.

The dataset provides high-frequency experimental data from the Mini Wheelbot, including onboard sensor measurements, robot state estimates, wheel motion, motor commands, setpoints, and motion-capture measurements. The data is recorded at **1 kHz** across different experimental conditions.

### Official Dataset Repository

The original dataset repository is maintained by the Wheelbot project:

**Mini Wheelbot Dataset**
https://github.com/wheelbot/dataset

The dataset is published through Zenodo. Please refer to the original repository for dataset documentation, download instructions, and licensing information.

### Dataset Usage in This Project

For this project, I use the Wheelbot dataset to perform a focused statistical analysis of the relationship between:

* **Drive-wheel angular velocity**
* **Robot pitch angle**

The original dataset is **not redistributed in this repository**. Only the analysis code, notebooks, results, and documentation developed for this project are maintained here.
