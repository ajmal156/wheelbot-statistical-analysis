# Dataset

This project uses the **Mini Wheelbot Dataset**.

The dataset contains sensor and motion data collected from a self-balancing robotic platform.

## Dataset Source

Please download the dataset from its official source:

* Zenodo dataset record
* Original Wheelbot dataset repository

The dataset is intentionally **not included in this GitHub repository** because of its large size and dataset licensing considerations.

## Expected Data

After downloading the dataset, place the required files in the appropriate local data directory.

Example:

```text
data/
├── README.md
└── raw/
    └── wheelbot_data.csv
```

Do not commit large raw datasets to GitHub.

## Citation

Please follow the citation and licensing requirements provided by the original dataset authors.
